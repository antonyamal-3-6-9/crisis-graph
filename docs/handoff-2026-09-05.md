## Completed Milestone 1: Directed Multi-Modal Pathfinder Upgrade
- Upgraded `DeterministicPathfinder` from `petgraph::graph::UnGraph` to `petgraph::graph::DiGraph<String, RoutingEdge>`.
- Implemented `RoutingEdge`, `RoutingQuery`, `CostMetric`, and `PathfinderError`.
- Enforces strict one-way constraints (preventing wrong-way highway/roundabout travel).
- Multi-modal vehicle capability filtering:
  - `Ambulance`: traverses emergency-cleared roads and residential lanes.
  - `EvacTruck`: avoids narrow alleys, service lanes, and tracks (`hgv: false` / `UNSUITABLE`).
- Dynamic operational hazard avoidance: accepts `blocked_segments` (floods/debris) and calculates safe detours.
- Fails closed if unreachable, triggering human dispatcher escalation.
- Verified on real Aluva pilot road segments in `tests/geospatial_tests.rs`.

## Completed Milestone 2: Neo4j Baseline Loader & Dynamic Overlay Integration
- Implemented `src/db/baseline_loader.rs` and CLI `src/bin/load_baseline_graph.rs`.
- Created uniqueness constraints and indexes on `(:Junction {id, dataset})` and `[:CONNECTS_TO {segment_id, dataset}]`.
- Batch-ingested 21,256 junctions and 48,626 directed segments in 7.11 seconds via Cypher `UNWIND`.
- Upgraded `StateManager` in `src/db/state_manager.rs`:
  - `get_passable_directed_subgraph(dataset)`: queries passable directed edges directly from Neo4j, automatically filtering out dynamically flooded or blocked segments where `operational_status IS NULL OR valid_until < datetime()`.
  - `apply_segment_hazard(segment_id, status, duration_hours)`: attaches bi-temporal operational hazard overlays to individual segments without modifying immutable baseline geometry.
  - `clear_operational_hazards(dataset)`: resets temporal hazard state.
- Registered Neo4j 5.26 as a systemd user service (`~/.config/systemd/user/neo4j.service`).
- Added full end-to-end integration test `tests/neo4j_baseline_tests.rs`, validating live Neo4j counts, multi-modal routing on real Aluva nodes, and dynamic flood detour avoidance.
- Total test suite: 16 passing tests (`cargo test`).
